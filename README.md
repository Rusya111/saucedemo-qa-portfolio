Привет! Это мое портфолио по ручному тестированию веб-приложений. 
В качестве объекта тестирования выбран демо-интернет-магазин **Swag Labs**, разработанный специально для практики QA-инженеров.

В проекте представлен полный цикл тестирования (STLC): от планирования и составления чек-листов до написания тест-кейсов и оформления баг-репортов.

## 📂 Структура репозитория

- 📄 **[Тест-план](test-plan/test-plan.md)** — стратегия, scope, риски, критерии входа/выхода.
- 📋 **[Чек-лист](checklists/checklist.md)** — 15 базовых проверок по 5 модулям (Smoke).
- 🧪 **[Тест-кейсы](test-cases/)** — 22 кейса, разбитых по модулям:
  - [Авторизация](test-cases/authorization.md)
  - [Каталог товаров](test-cases/catalog.md)
  - [Корзина](test-cases/cart.md)
  - [Оформление заказа](test-cases/checkout.md)
- 🐞 **[Баг-репорты](bug-reports/bug-reports.md)** — 5 задокументированных дефектов с классификацией Severity и Priority.
- 📦 **[Sources](sources/)** — исходные файлы артефактов (.docx, .xlsx).
